# ScreenText Helper

Windows приложение для захвата области экрана, распознавания текста (OCR) и перевода.

## Описание

Приложение работает в фоновом режиме и управляется горячими клавишами:
- **Ctrl+Alt+S** - Распознать текст в выделенной области
- **Ctrl+Alt+T** - Перевести текст в выделенной области

## Возможности

- 🎯 Захват области экрана мышью
- 🔍 Распознавание текста с помощью OCR
- 🌍 Перевод текста на разные языки
- 🖥️ Работа в системном трее
- ⚙️ Настраиваемые горячие клавиши
- 🎨 Настраиваемый интерфейс

## Требования

- Python 3.8+
- Windows 10/11
- Интернет-соединение (для перевода)

## Использование

1. **Распознавание текста**:
   - Нажмите **Ctrl+Alt+S**
   - Выделите область с текстом мышью
   - Текст будет скопирован в буфер обмена

2. **Перевод текста**:
   - Нажмите **Ctrl+Alt+T**
   - Выделите область с текстом мышью
   - Перевод появится поверх экрана

3. **Настройки**:
   - Кликните правой кнопкой мыши по иконке в системном трее
   - Выберите "Настройки"
   - Измените горячие клавиши, языки и внешний вид

## Разработка

### Стек технологий:
- PyQt6 - GUI фреймворк
- EasyOCR - распознавание текста
- Google Translate API - перевод текста
- keyboard - обработка горячих клавиш
- pyautogui - захват экрана

### Архитектура:
- **MVC паттерн** - разделение логики и интерфейса
- **Сигнальная система** - связь между компонентами
- **Настройки** - JSON файл для конфигурации
- **Логирование** - запись событий в файл

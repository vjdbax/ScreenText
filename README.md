## Для чего это нужно?

**ScreenText Helper** — это оверлей-утилита, которая мгновенно распознаёт и переводит текст прямо с экрана. Никаких переключений окон, копирования в Google Translate или скриншотов через «Ножницы».

### Идеальные сценарии использования

| Сценарий | Проблема | Решение |
|----------|----------|---------|
| **Игры без локализации** | Квесты, диалоги, квестовые журналы на английском | Выдели область — получи перевод поверх игры |
| **Манга / комиксы** | Текст в картинках, нельзя скопировать | ИИ-модель распознает даже мелкий шрифт |
| **Защищённые документы** | PDF, скриншоты, веб-страницы с блокировкой выделения | Захват области → OCR → перевод |
| **Работа через RDP / виртуальную машину** | Нет общего буфера обмена между системами | Перевод прямо с экрана удалённого рабочего стола |
| **Онлайн-курсы и вебинары** | Субтитры, презентации на чужом языке | Мгновенный перевод без паузы |
| **Чтение документации** | Stack Overflow, GitHub, технические статьи | Ctrl+Home — перевод выделенного текста |

## Ключевые возможности

### :zap: Нативный селектор экрана

Полноэкранный оверлей для выделения области мышью — **без сворачивания окон, без «Ножниц Windows», без лишних диалогов**. Поддержка мультиэкрана и HiDPI.

### :brain: Локальный ИИ через Ollama

Распознавание и перевод **без интернета и утечки данных**. Рекомендуемые модели:
- **Qwen 2.5 VL** — отличное качество распознавания
- **MiniCPM-V** — быстрая работа на слабых ПК

Встроенный менеджер скачивает и удаляет модели в один клик.

### :ocean: Потоковый стриминг перевода (SSE)

Перевод отображается **посимвольно, в реальном времени** — не нужно ждать, пока весь текст переведётся. Работает с Ollama, OpenRouter и любым OpenAI-совместимым API.

### :book: Книжная верстка HTML

Сохраняется структура оригинала: **заголовки, абзацы, дефисы, переносы строк**. Не «стена текста», а читаемый документ с форматированием.

### :globe_with_meridians: Множество переводчиков

| Движок | Особенности |
|--------|-------------|
| **Google Translate** | Быстро, бесплатно, 100+ языков |
| **DeepL** | Высокое качество, требует API-ключ |
| **MyMemory** | Бесплатная альтернатива DeepL |
| **Ollama / OpenRouter** | Локальный или облачный ИИ |
| **Белорусская латиница (Łacinka)** | Конвертация кириллицы в классическую латиницу |

## Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| <kbd>Ctrl</kbd> + <kbd>End</kbd> | Захват области экрана → OCR + перевод |
| <kbd>Ctrl</kbd> + <kbd>Home</kbd> | Перевод выделенного текста |

Горячие клавиши полностью настраиваются в меню **Настройки**.

## Настройка локального ИИ за 2 минуты

Встроенный менеджер Ollama делает всё автоматически:

```
1.  Правый клик по иконке в трее → Настройки
2.  Нажать «Установить локальный ИИ (Ollama)»
3.  Выбрать модель (рекомендуется qwen2.5vl:3b) → Скачать
4.  Включить галочку «Использовать Vision-to-Text (ИИ)»
5.  Готово! Работает без интернета
```

> :bulb: **Совет:** Модель `qwen2.5vl:3b` весит ~2 GB и работает на любой modern видеокарте с 4+ GB VRAM. Для лучшего качества используйте `qwen2.5vl:7b`.

## Быстрый старт

### Вариант 1: Скачать готовый установщик

1. Скачайте `ScreenTextHelper_v5.5.0_Setup.exe` из раздела [Releases](../../releases)
2. Запустите установщик — выберите папку, поставьте галочку «Создать ярлык на рабочем столе»
3. Запустите ScreenText Helper из Меню Пуск или с рабочего стола

### Вариант 2: Запуск из исходников

```bash
# Клонировать репозиторий
git clone <repository-url>
cd ScreenText_v5_5

# Установить зависимости
pip install -r requirements.txt

# Запустить
python run.py
```

### Вариант 3: Собрать .exe самостоятельно

```bash
# Собрать дистрибутив + инсталлятор
python build_exe.py

# Результат:
#   dist/ScreenTextHelper/ScreenTextHelper.exe
#   dist_installer/ScreenTextHelper_v5.5.0_Setup.exe
```

## Сборка инсталлятора

### Требования

- Python 3.10+
- [Inno Setup 6+](https://jrsoftware.org/isinfo.php) (опционально, для создания Setup.exe)

### Автоматическая сборка

```bash
python build_exe.py
```

Скрипт выполнит:
1. Установку зависимостей
2. Предзагрузку моделей EasyOCR
3. Компиляцию .exe через PyInstaller
4. Создание инсталлятора через Inno Setup (если найден)

### Ручная сборка инсталлятора

```bash
# Если Inno Setup установлен
iscc.exe installer.iss
```

Результат: `dist_installer/ScreenTextHelper_v5.5.0_Setup.exe`
